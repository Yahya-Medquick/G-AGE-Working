"Working" means an implementation and a connected code path exist, not that a live deployment or external credentials were exercised. "Partial" means a code path exists but is incomplete, inconsistent, or not wired to the currently mounted UI. "Dead code" means the frontend definition is not reached from the current `App` entry point.
